


## 🎥 استریم نینجا | Stream Ninja

## Stream Ninja چیست؟ 🚀
Stream Ninja (نسخه سفارشی‌شده VDO.Ninja) یک ابزار استریم ویدیو همتا به همتا (Peer-to-Peer) است که برای اتصال دوربین از راه دور به OBS و سایر نرم‌افزارهای استودیویی طراحی شده و اکنون از طریق سایت remoteVm.site در دسترس است. ویژگی‌های اصلی:

🔒 ارتباط مستقیم ویدیو بین کاربران بدون نیاز به سرور مرکزی در اکثر موارد

⚡ کیفیت بسیار بالا با تأخیر بسیار پایین

🧑‍💼 کنترل پنل کارگردان با قابلیت گفت‌و‌گوی گروهی

📱 امکان استفاده از موبایل به عنوان وبکم بی‌سیم

🌐 پشتیبانی از WHIP/WHEP و امکان راه‌اندازی سرور اختصاصی SFU



## نحوه استفاده 📝
کافی‌ست مرورگر خود را باز کرده و وارد Stream Ninja شوید و گزینه «افزودن دوربین به OBS» را انتخاب کنید.

## توسعه و نسخه‌های انتشار
🌙 نسخه alpha (آزمایشی): مناسب برای توسعه‌دهندگان و تست ویژگی‌های جدید

🛠 نسخه release (پایدار): برای استفاده در محیط‌های تولید و بدون تغییرات مکرر

زیرساخت و سرور
Stream Ninja طراحی شده تا تقریباً بدون نیاز به سرور مرکزی کار کند:

🔹 95٪ اتصال‌ها به‌صورت مستقیم Peer-to-Peer برقرار می‌شوند.

🔹 استفاده از STUN، TURN و سرور Handshake برای اتصال اولیه

🔹 برای افزایش حریم خصوصی و امنیت، طراحی نزدیک به 100٪ بدون سرور است.



## پروژه‌های مرتبط
🎥 Electron Capture
ابزاری قدرتمند برای "ضبط پنجره" در ویندوز و جایگزین بهتر برای OBS Browser Source
🔗 لینک پروژه

🌐 Social Stream Ninja
افزونه رایگان کروم برای نمایش پیام‌های زنده از پلتفرم‌های اجتماعی روی استریم شما

اگر می‌خواهید نسخه فارسی‌سازی‌شده یا اختصاصی از Stream Ninja را با دامنه‌ی خود میزبانی کنید، با ما تماس بگیرید.
ما آماده‌ایم تا نسخه‌ای مخصوص برند شما راه‌اندازی کنیم.

Stream Ninja - از استودیوهای حرفه‌ای تا استریمرهای شخصی، راهکاری مدرن برای اتصال تصویری با کیفیت بالا از راه دور.
