## نحوه استفاده 📝
کافی‌ست مرورگر خود را باز کرده و وارد Stream Ninja شوید و گزینه «افزودن دوربین به OBS» را انتخاب کنید.

## توسعه و نسخه‌های انتشار
🌙 نسخه alpha (آزمایشی): مناسب برای توسعه‌دهندگان و تست ویژگی‌های جدید

🛠 نسخه release (پایدار): برای استفاده در محیط‌های تولید و بدون تغییرات مکرر

زیرساخت و سرور
Stream Ninja طراحی شده تا تقریباً بدون نیاز به سرور مرکزی کار کند:

🔹 95٪ اتصال‌ها به‌صورت مستقیم Peer-to-Peer برقرار می‌شوند.

🔹 استفاده از STUN، TURN و سرور Handshake برای اتصال اولیه

🔹 برای افزایش حریم خصوصی و امنیت، طراحی نزدیک به 100٪ بدون سرور است.




اگر می‌خواهید نسخه فارسی‌سازی‌شده یا اختصاصی از Stream Ninja را با دامنه‌ی خود میزبانی کنید، با ما تماس بگیرید.
ما آماده‌ایم تا نسخه‌ای مخصوص برند شما راه‌اندازی کنیم.

Stream Ninja - از استودیوهای حرفه‌ای تا استریمرهای شخصی، راهکاری مدرن برای اتصال تصویری با کیفیت بالا از راه دور.
