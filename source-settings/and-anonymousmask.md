# \&anonymousmask

Sender-Side Option! ([`&push`](push.md))

## Aliases

* `&anonmask`

## Details

`&anonymousmask` is a shortcut for [`&effects=anon`](effects.md). It applies an anonymous mask over detected faces, hiding the sender's identity while still showing movement.

{% hint style="info" %}
This is an experimental effect. Loading may take a moment as it downloads a custom effects model.
{% endhint %}
