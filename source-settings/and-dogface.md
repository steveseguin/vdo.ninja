# \&dogface

Sender-Side Option! ([`&push`](push.md))

## Aliases

* `&dogears`

## Details

`&dogface` is a shortcut for [`&effects=dog`](effects.md). It overlays dog ears and a nose on detected faces.

{% hint style="info" %}
This is an experimental effect. Loading may take a moment as it downloads a custom effects model.
{% endhint %}
