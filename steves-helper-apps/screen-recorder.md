# Screen Recorder

The Screen Recorder is a standalone capture tool in the VDO.Ninja project for local-first recording workflows.

## Link

* [https://vdo.ninja/screenrecorder/](https://vdo.ninja/screenrecorder/)

## Key features

* Screen + webcam overlay recording flow
* Countdown and recording transport controls
* Local recording focus with export/download options
* Utility options for transcription and capture workflows

This tool is separate from the main director room UI and is intended as a dedicated recorder surface.
