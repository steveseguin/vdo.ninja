Live translation setup

One person supplies the translation account. Everyone else joins normally and only chooses the language they want to hear.

1. Translation account

Alpha BYOK mode: by default, the key is handed to the translation page once and then kept only in memory. It is never added to generated links or sent to other participants. Use a dedicated, restricted key with a low spending limit.

Optional self-hosted token broker

When a broker URL is set, the browser asks it for a short-lived OpenAI client secret instead of receiving your OpenAI key. The broker URL may be added to the account-holder link; the broker token never is.

2. Make the account-holder link

Paste the normal VDO.Ninja link used by the person paying for translation.

Use Save and open to pass credentials in this tab. Copied links do not carry credentials; for another site or browser, run translation setup there.

3. Make the participant link

Paste the normal guest or participant invite. Participants do not need an OpenAI account or API key.
