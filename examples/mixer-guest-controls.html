Mixer guest controls

To share layout control, open a main Mixer, enable Allow for remote co-directors in its director controls, then click Open co-Mixer. Share that tab's URL with your operators.

Co-Mixers show the main Mixer's saved layouts and current selection. Operators can switch, create, edit, duplicate and remove layouts. Saved changes appear for everyone; unsaved edits stay local. If another operator changes the same layout, reopen it or duplicate your draft to keep both versions. Keep the main Mixer open: it stores the layouts and controls the output.

Guest previews and controls remain available. In Mixer Settings, enable Show advanced controls for the additional guest settings. General Mixer settings and layout ordering are managed in the main Mixer.

The shared-layout URL uses &mixercontrols=layouts. For guest controls without the layout editor, use the mode below.

Guest controls only

Add &mixercontrols=guests to a mixer URL containing the room name and existing co-director credentials. Include the room password if required.

mixer.html?room=ROOM&codirector=CO_PASSWORD&password=ROOM_PASSWORD&mixercontrols=guests

This opens the ordinary Director's Room controls inside the mixer page and automatically adds &noclaim. The main director must enable co-directors and provide the co-director password. The URL option does not grant permissions.

Guest thumbnails, guest controls and Solo Talk use the existing director implementation. The mixer layout editor, automatic slot reservations and saved-layout publishing do not start. This mode does not include a separate Program preview.
