# \&roomonlylowbitrate

Room Option! ([`&room`](../../general-settings/room.md))

## Details

`&roomonlylowbitrate` is an alias for [`&roomtier1bitrate`](roomtier1bitrate.md).

Example:

`&roomonlylowbitrate=1500`

Use it to set the lower automatic room-only bitrate tier for weaker mobile devices.
