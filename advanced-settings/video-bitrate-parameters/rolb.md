# \&rolb

Room Option! ([`&room`](../../general-settings/room.md))

## Details

`&rolb` is a short alias for [`&roomtier1bitrate`](roomtier1bitrate.md).

Example:

`&rolb=1500`

Use it to set the lower automatic room-only bitrate tier for weaker mobile devices.
