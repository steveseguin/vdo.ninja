# \&rob

Room Option! ([`&room`](../../general-settings/room.md))

## Details

`&rob` is a short alias for [`&roomtier2bitrate`](roomtier2bitrate.md).

Example:

`&rob=2000`

Use it to set the higher automatic room-only bitrate tier for normal or stronger devices.
