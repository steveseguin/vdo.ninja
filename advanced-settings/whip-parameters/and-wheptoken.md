# \&wheptoken

Viewer-Side Option! ([`&whep`](and-whep.md))

## Aliases

* `&whepplaytoken`

## Options

Example: `&wheptoken=YOUR_BEARER_TOKEN`

| Value   | Description                        |
| ------- | ---------------------------------- |
| String  | WHEP bearer/authorization token    |

## Details

- Supplies an auth token for the WHEP endpoint when using [`&whep`](and-whep.md).
- Token is sent as required by the WHEP server (implementation-dependent).
