# \&pagezoom

Viewer-Side Option! ([`&view`](../view-parameters/view.md), [`&scene`](../view-parameters/scene.md), [`&room`](../../general-settings/room.md))

## Options

Example: `&pagezoom`

| Value      | Description                           |
| ---------- | ------------------------------------- |
| (no value) | Enables an on-screen zoom slider      |

## Details

- Adds a bottom overlay slider to scale the grid/container, with proper centering and scroll handling.
- Updates viewport meta to allow user scaling on mobile (`maximum-scale=4.0`).
- Handy for fine control in full-screen scenes or signage displays.
