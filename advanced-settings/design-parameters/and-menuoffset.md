# \&menuoffset

General option (works with [`&push`](../../source-settings/push.md) and viewer links).

`&menuoffset=<px>` adjusts the vertical position of the on-page control buttons (menu/mute strip). Useful when embedding under another overlay so the buttons don’t overlap.

Example: `&menuoffset=80` lifts the buttons 80px from the bottom.
