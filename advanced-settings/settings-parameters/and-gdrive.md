# \&gdrive

Advanced/Integration Option!

## Options

Example: `&gdrive`

| Value      | Description                          |
| ---------- | ------------------------------------ |
| (no value) | Enables Google Drive integration     |

## Details

- Enables code paths for Google Drive upload/backup features where available (experimental/limited).
- Requires user authentication and appropriate scopes (handled by the UI when supported).
- Behavior may change; intended for advanced users.
