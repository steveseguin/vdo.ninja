# \&screensharestyle / \&ssstyle

General option (works with [`&push`](../../source-settings/push.md) and viewer links).

`&screensharestyle=` picks an internal style preset for how the screen-share preview/dock is placed. Current values are numeric; `1` is the default and other values are experimental/subject to change.

Example: `&screensharestyle=2`
