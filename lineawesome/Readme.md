# Line Awesome — Icons8

This directory contains the following unmodified files from
[`line-awesome@1.3.0`](https://registry.npmjs.org/line-awesome/1.3.0):

- `css/line-awesome.css` and `css/line-awesome.min.css`.
- `fonts/la-solid-900.eot`, `.svg`, `.ttf`, `.woff`, and `.woff2`.

All seven files were verified byte for byte against their counterparts under
`dist/line-awesome/` in the
[published npm archive](https://registry.npmjs.org/line-awesome/-/line-awesome-1.3.0.tgz).
Only the solid font is included in this checkout.
